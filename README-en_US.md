## 📖 About the Project

**Stardew Valley Repository** is an unofficial archive of historical Stardew Valley versions. The project aims to organize version information, changelogs, and sources for obtaining related files, providing players with a convenient and intuitive way to browse and download different game versions.

The repository currently focuses on the **Android** platform, with plans to gradually expand to other platforms where feasible.

---

## ✨ Key Features

- **Historical Version Archive**: Collects and organizes basic information and download sources for different game versions.
- **Version Information**: Provides version numbers, release dates, changelogs, and other relevant details.
- **File Information**: Documents file sizes, supported architectures, checksums, and related information.
- **Ongoing Maintenance**: Corrects inaccurate records and adds missing versions and historical information.
