使用指南
  • 1. 这里收录了什么：

    版本库收录了 Stardew Valley 在 Android 平台发布过的所有版本。iOS 版本有收录的计划，但由于开发者目前没有 iPhone 设备，暂时无法实现。至于 Windows 版本，私以为没有收录的必要。如果你有好的解决办法或者其他好的想法，欢迎与开发者取得联系。如果在使用过程中发现版本数据存在问题或更新不及时，欢迎通过站点下方的群聊和频道与我们取得联系。

  • 2. 如何选择安装包类型：

    从 1.5 版本起，官方开始使用 Android App Bundle 技术构建安装包，通过这种技术构建的安装包文件扩展名为 APKS 而不是传统的 APK。但遗憾的是，目前大部分普通安装器并不支持安装 APKS 文件，通常需要使用专门的安装工具（例如 MT管理器或 Split APKs Installer (SAI)）才能安装。因此，版本库同时提供了官方原版与重打包版以方便不同需求的用户选择下载。官方原版是从谷歌商店提取的原始安装包，重打包版是将原始安装包转成 APK 的产物。两者的区别仅在于安装包形式与应用签名，一般情况下推荐安装官方原版，否则请选择重打包版。另外，需要注意的是，重打包版使用的是个人签名，可能会与设备上原有的应用签名不一致，你可以选择卸载重装（这极大可能会丢失你的全部游戏数据）或通过原分发渠道进行更新。

  • 3. 如何选择安装包架构：

    从 1.6 版本起，官方将原本一个包含多种 CPU 架构的安装包拆分为了多个单 CPU 架构的安装包包，因此你需要根据设备所使用的 CPU 架构选择对应的安装包。ARMv7 主要适用于较老的 32 位 ARM 设备；ARMv8（ARM64）适用于目前绝大多数 Android 手机和平板；x86 主要用于较早期的 Intel/AMD 32 位 Android 设备或较早期的 Android 模拟器；x86_64 则适用于 64 位 Intel/AMD Android 设备或 Android 模拟器；Universal 则包含了上面列出的全部 CPU 架构。如果不确定自己的设备架构，可以使用 DevCheck 查询或通过搜索引擎查找。此外版本库页面顶部也显示出了浏览器返回的当前设备信息，但受限于安全策略，该信息仅供参考，不一定准确。
